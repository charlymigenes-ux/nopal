## [1.2.0-alpha.1] — 2026-08-10

First tagged GitHub release. NOPAL had already been under active development for several weeks before this point — this tag is a snapshot to give the project a real version history going forward, not a claim that everything below shipped at once. See the [commit history](https://github.com/charlymigenes-ux/nopal/commits/main) for the full detail.

As of this tag, NOPAL includes:

- Unified dashboard for 3D printers (Klipper/Moonraker, standalone Marlin, Bambu Lab, Elegoo, FlashForge), GRBL laser/CNC control, and a 3D model / G-code library.
- Plugin system: materials inventory (Spoolman), job quoting, camera viewer, Arduino/ESP32 workshop automation, LED matrix panel.
- TUNA-Screen, a companion Android app for phone/tablet control.
- Light, Dark, NOPAL Style, and Desert themes, with a full color/background editor.
- Public landing page and community collaboration program (`/colabora`) for registering hardware to test.
