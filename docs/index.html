Características

Todo tu taller, en un solo panel

Impresoras 3D de 5 marcas, láser/CNC GRBL, una galería de plugins y tu biblioteca de modelos, en una sola aplicación web servida desde un host en tu red local.

Dashboard unificado

Todas las impresoras, láseres y CNC de la red en una vista, clasificados por color según tipo y estado, en tarjetas o lista compacta.

Impresoras 3D — 5 marcas, una interfaz

Klipper/Moonraker, Marlin standalone, Bambu Lab, Elegoo y FlashForge: temperaturas en vivo, movimiento del cabezal y cola de impresión con ETA. Cada marca con su propio driver, fiel a cómo habla ese hardware.

Láser y CNC (GRBL)

Placas por red (ESP3D/FluidNC) o USB/serial, varias a la vez. El mismo hardware se registra como láser (potencia/aire asistido) o CNC (spindle/refrigerante) según el rol, con jog, home y consola GRBL en vivo.

Biblioteca de modelos y G-code

Explora, busca y previsualiza en 3D archivos STL/3MF/STEP y G-code. Envíalos a la cola, a la tarjeta SD o directo a una máquina.

Historial de trabajos

Registro buscable, por máquina, de cada impresión o corte completado, cancelado o con error.

Galería de plugins

Suma Materiales (inventario de filamento vía Spoolman), Cotizador, Cámaras y Automatización de Taller (Arduino/ESP32) — sin modificar el núcleo de NOPAL.

TUNA-Screen (app Android)

Vincula un celular o tablet con un código de 6 dígitos y controla cualquier máquina — o montá una tablet en la impresora como pantalla de estado dedicada.

Editor de parámetros GRBL

Lee y escribe cada parámetro $$ de la controladora, con descripción en lenguaje claro.

Temas personalizados

Light, Dark, NOPAL Style y Desert, más un editor completo de colores e imagen de fondo. Interfaz bilingüe ES/EN.

Arquitectura

Un host, toda tu red de máquinas

El servidor de NOPAL (Python/FastAPI) corre en un host Debian/Raspberry Pi OS/Ubuntu, junto con una instancia de Moonraker por impresora Klipper. Las demás marcas hablan cada una su propio protocolo directo con el equipo (MQTT para Bambu Lab, WebSocket/SDCP para Elegoo, HTTP para FlashForge), y los láseres/CNC GRBL se conectan por WiFi (ESP3D/FluidNC) o por USB/serial. Los plugins son repositorios aparte, clonados y cargados en caliente; TUNA-Screen habla con NOPAL por su propia API REST + WebSocket, nunca directo con el hardware.

PuertoServicio
8420Interfaz web de NOPAL (configurable con NOPAL_PORT)
7125–7127…Una instancia de Moonraker por impresora Klipper
MQTT / WS / HTTPBambu Lab, Elegoo y FlashForge — directo al equipo, sin puerto adicional en el host
8080Crowsnest (streaming de cámaras), si está habilitado
SerialPlacas láser/CNC GRBL por USB (/dev/ttyUSB*)
Instalación

Listo en un par de minutos

Requisitos: Python 3.9+, un usuario Linux no-root con acceso a sudo, y acceso de red a tus impresoras/láseres.

1
Clona el repositorio

Descarga el código en tu host Linux.

2
Ejecuta el instalador

install.sh crea el entorno virtual, instala dependencias y genera el servicio systemd.

3
Abre NOPAL en tu navegador

El instalador imprime la URL local, por defecto en el puerto 8420.

bash — instalación 
# clonar e instalar
git clone https://github.com/charlymigenes-ux/nopal.git ~/nopal
cd ~/nopal
./install.sh

# opcional: usar otro puerto
NOPAL_PORT=9000 ./install.sh
